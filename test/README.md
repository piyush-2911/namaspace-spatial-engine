# Test input setup

No raw video or extracted dataset frames are bundled in this repository.

For local input testing, obtain the Meetingroom video or image set directly from the [official Tanks and Temples download page](https://www.tanksandtemples.org/download/) after reviewing the [source license](https://www.tanksandtemples.org/license/). Alternatively, use your own indoor capture. Keep downloaded images and videos local.

Follow [RECONSTRUCTION.md](../RECONSTRUCTION.md) for complete reconstruction instructions. The full-video notebooks require their full inputs; a short subset will not pass their frame-count gates.

The public site retains the reconstructed models. Source frames have been removed from this repository.
